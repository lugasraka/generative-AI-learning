# Agentic AI Crash Course — Vibe-Coded Labs

A hands-on, vibe-coding companion to the [Agentic AI Crash Course](../agentic_ai_crash_course/).

## What this is

The original course is conceptual — 10 parts, no code. This folder gives you a
**vibe-coding challenge per part**. You drive the code; I help you build it.

## How to use

1. Open the part folder (e.g. `part1_what_are_ai_agents_anyway/`).
2. Read the `README.md` — 5-10 line concept + 1 vibe-coding challenge.
3. Tell me what you want to build (or ask me to scaffold it).
4. We iterate. You run things, I adjust.
5. Mark the part done in `PROGRESS.md` when you feel comfortable.

## Rules of the road

- **No API keys required.** We use opencode itself as the LLM, or pure logic.
- **No production code expected.** Goal is to internalize the concept, not ship.
- **Problem-first.** Each lab starts with a real-world problem, not an architecture.
- **Vibe coding welcome.** Prompts like *"make it smaller"*, *"add X"*, *"why did this happen?"* are the whole point.
