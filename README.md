# Generative AI Learning

Lab companions for [awesome-generative-ai-guide](https://github.com/aishwaryanr/awesome-generative-ai-guide). I don't retain things by reading once, so I turn each chapter into a coding challenge that runs.

## Tracks

| Track | Units | Time |
| --- | --- | --- |
| Agentic AI Crash Course | 10 parts | 15-30 min |
| AI Evals for Everyone | 11 chapters | 20-40 min |
| Applied LLMs Mastery 2024 | 12 parts | 15-30 min |
| Agentic RAG 101 | 6 parts | 10-15 min |
| LLM Agents 101 | 6 parts | 10-20 min |
| Securing Agentic AI | 9 parts | 15-20 min |

Each track has a read-only course folder and a `*_labs/` folder with runnable scripts. One subdirectory per part.

## How to use

1. Pick a track → read a part → open the matching `*_labs` folder.
2. Read the README, build the challenge, iterate.
3. Tick it off in PROGRESS.md.

## Rules

- **No API keys.** Everything runs through the opencode CLI or pure logic. Local only.
- **Ugly is fine.** Code that runs and teaches beats code that's clean and doesn't.
- **Problem first.** Real problem → then architecture.
- **Vibe code.** I drive, the assistant scaffolds. "Make it tighter" is the point.
