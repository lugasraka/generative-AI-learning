# Applied LLMs Mastery — Vibe-Coded Labs

A hands-on, vibe-coding companion to the
[Applied LLMs Mastery 2024](../Applied_LLMs_Mastery_2024/) course.

## What this is

The original course is conceptual — 12 weeks, no code. This folder gives you a
**vibe-coding challenge per part**. You drive the code; your AI assistant helps
you build it.

## How to use

1. Open the source week in `Applied_LLMs_Mastery_2024/` (e.g. `week2_prompting.md`).
2. Open the matching lab part (e.g. `part3_prompting_and_prompt_engineering/`).
3. Read the `README.md` — concept summary + vibe-coding challenge.
4. Tell your AI assistant what you want to build (or paste the "How to start" prompt).
5. We iterate. You run things, the assistant adjusts.
6. Mark the part done in `PROGRESS.md` when you feel comfortable.

## Rules of the road

- **No API keys required.** We use opencode itself as the LLM, or pure logic.
- **No production code expected.** Goal is to internalize the concept, not ship.
- **Problem-first.** Each lab starts with a real-world problem, not an architecture.
- **Vibe coding welcome.** Prompts like "make it smaller", "add X", "why did this
  fail?" are the whole point.
