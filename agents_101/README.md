# LLM Agents 101

A self-paced course on LLM agents — what they are, what's inside them, how multi-agent systems work, real-world applications, evaluation, and hands-on resources to build your own.

## Parts

1. [Introduction to LLM Agents](part1_introduction_to_llm_agents.md) — The model-plus-harness concept and a practical vacation planning example.
2. [What's Inside an Agent: The Harness](part2_whats_inside_an_agent.md) — The four components: agent core, memory, tools, and planning.
3. [Multi-Agent Systems](part3_multi_agent_systems.md) — Cooperative vs adversarial patterns and when to use multiple agents.
4. [Agents in the Real World](part4_agents_in_the_real_world.md) — Coding agents, computer-use, deep research, and enterprise workflows.
5. [Evaluating Agents](part5_evaluating_agents.md) — Utility, reliability, and safety dimensions for agent evaluation.
6. [Build Your Own Agent](part6_build_your_own_agent.md) — Learning resources and academic references.
