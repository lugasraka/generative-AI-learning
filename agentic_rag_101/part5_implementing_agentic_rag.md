# Part 5: Implementing Agentic RAG

Here are some resources you can use to get started with implementing Agentic RAG:

## Implementation Guides

1. [Implementing Agentic RAG Using LangChain](https://medium.com/the-ai-forum/implementing-agentic-rag-using-langchain-b22af7f6a3b5) — A hands-on guide to building an Agentic RAG pipeline with LangChain.

2. [Agentic RAG with LangChain and Pinecone](https://github.com/benitomartin/agentic-rag-langchain-pinecone) — A complete GitHub repository with code for an Agentic RAG system using LangChain and Pinecone.

3. [Agentic RAG with LlamaIndex](https://www.llamaindex.ai/blog/agentic-rag-with-llamaindex-2721b8a49ff6) — Official blog post from LlamaIndex on building Agentic RAG workflows.

4. [Agentic RAG Using Vertex AI](https://docs.llamaindex.ai/en/stable/examples/agent/agentic_rag_using_vertex_ai/) — LlamaIndex documentation showing how to implement Agentic RAG with Google Vertex AI.

5. [Building Agentic RAG Systems with LangGraph](https://www.analyticsvidhya.com/blog/2024/07/building-agentic-rag-systems-with-langgraph/) — A tutorial on building Agentic RAG systems using LangGraph for more complex orchestration.
