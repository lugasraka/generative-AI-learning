# Agentic RAG 101 — Vibe-Coded Labs

A hands-on, vibe-coding companion to the [Agentic RAG 101](../agentic_rag_101/) course.

## What this is

The original course is conceptual — 6 parts, no code. This folder gives you a
**vibe-coding challenge per part**. You drive the code; I help you build it.

## How to use

1. Read the part in `agentic_rag_101/` (e.g. `part1_understanding_rag_and_agents.md`).
2. Open the matching lab folder (e.g. `part1_understanding_rag_and_agents/`).
3. Read the `README.md` — concept recap + vibe-coding challenge.
4. Tell me what you want to build (or ask me to scaffold it).
5. Mark the part done in `PROGRESS.md` when you feel comfortable.

## Rules of the road

- **No API keys required.** We use opencode itself as the LLM, or pure logic.
- **No production code expected.** Goal is to internalize the concept, not ship.
- **Problem-first.** Each lab starts with a real-world problem, not an architecture.
- **Vibe coding welcome.** Prompts like *"make it smaller"*, *"add X"*, *"why did this happen?"* are the whole point.
