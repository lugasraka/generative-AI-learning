# Securing Agentic AI Systems

A self-paced course on securing AI agents — covering attack vectors, defense architecture, detection/prevention/mitigation, security frameworks, implementation, vulnerability mitigation, monitoring, and security-by-design principles.

## Parts

1. [Understanding Agentic AI Security](part1_understanding_agentic_ai_security.md) — What makes agents different, why traditional security fails, the four key security challenges, and a quick reference of critical controls.
2. [Attack Vectors in Agentic Systems](part2_attack_vectors.md) — The five primary attack vectors: prompt injection, memory poisoning, supply chain, tool misuse, and goal hijacking.
3. [Defense Architecture: The Three-Pillar Approach](part3_defense_architecture.md) — Guardrails, permissions, and auditability. The governance-containment gap.
4. [Detection, Prevention, and Mitigation Strategies](part4_detection_prevention_mitigation.md) — Layered defenses: real-time detection, input validation and prevention, blast-radius mitigation.
5. [Security Frameworks for Agentic AI](part5_security_frameworks.md) — OWASP Top 10 for Agentic Applications, NIST AI RMF, and MITRE ATLAS.
6. [Implementation Guide](part6_implementation_guide.md) — Identity/access, containment controls, tamper-resistant logging, and security testing.
7. [Addressing Specific Vulnerabilities](part7_addressing_vulnerabilities.md) — Targeted defenses against each of the five attack vectors.
8. [What to Watch For in Your Systems](part8_what_to_watch_for.md) — Warning signs, behavioral anomalies, log patterns, and escalation triggers.
9. [Building Security by Design](part9_building_security_by_design.md) — Security requirements, secure development practices, compliance, and continuous improvement.
